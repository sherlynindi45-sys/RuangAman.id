# RuangAman.id
RuangAman.id adalah website edukasi interaktif Anti-Cyberbullying &amp; Etika Daring untuk proyek PSAS Informatika pada materi Dampak Sosial Informatika &amp; Pengembangan Website Berbantuan AI. Situs ini menanggapi normalisasi perundungan pelajar—seperti ejekan fisik, nama orang tua, sebar aib, dan pengucilan—yang dianggap candaan di obrolan maupun gim.
